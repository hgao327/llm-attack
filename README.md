# LLM Attack

Adversarial attack methods for Large Language Models.

## Structure

```
llm-attack/
├── data/                    # C4 dataset
├── LLM-Attack-Baseline/     # Attack methods (Hotflip, UAT, AutoPrompt, GCG)
├── autoprompt/              # AutoPrompt library
├── llm-attacks/             # GCG library
└── classification/          # Classification experiments
```
